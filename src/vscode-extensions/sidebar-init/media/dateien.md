# Deine Dateien

Dein Workspace ist ein kleiner Linux-Rechner, der nur dir gehört. Was du im Ordner **workspace** anlegst, liegt auf dem Server, nicht auf diesem Computer.

- **Open Folder**: einen Ordner öffnen, zum Beispiel den eines Projekts.
- **Clone Repository**: eine Vorlage aus dem Internet holen; die Adresse steht auf der Seite der Aktivität.
- Im geöffneten Ordner: Neue Datei mit dem Blatt mit dem Plus, neuer Ordner mit dem Ordner mit dem Plus.
