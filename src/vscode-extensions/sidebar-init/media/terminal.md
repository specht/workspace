# Das Terminal

Ein paar Befehle für den Anfang:

| Befehl | Was er tut |
| --- | --- |
| `ls` | zeigt, was im Ordner liegt |
| `cd ordner` | wechselt in einen Ordner |
| `cd ..` | geht einen Ordner zurück |
| `ruby hallo.rb` | startet ein Ruby-Programm |

Ein laufendes Programm hältst du mit **Strg+C** an.
