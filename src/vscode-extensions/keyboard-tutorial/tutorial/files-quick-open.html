Eine Datei schnell öffnen

Mit Strg + P öffnest du die Dateisuche. So findest du eine Datei anhand ihres Namens, ohne die vielen Unterordner im Explorer aufklappen zu müssen. Bestätige den passenden Treffer mit Enter.
