Tutorial-Arbeitsordner schließen

Für dieses Kapitel hat das Tutorial den eigenen Arbeitsordner Tastatur-Tutorial geöffnet. Wenn du mit einem Projekt fertig bist, kannst du den geöffneten Ordner über Datei → Ordner schließen wieder verlassen.

In VS Code Web wird die Seite dabei neu geladen. Der folgende Button schließt den Ordner und öffnet das Tutorial danach automatisch wieder, damit du direkt auf der Abschlussseite landest.
