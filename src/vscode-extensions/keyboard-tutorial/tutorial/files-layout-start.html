Explorer und Tutorial nebeneinander

In den nächsten Übungen arbeitest du links im Explorer. Dafür öffnet das Tutorial einen eigenen Arbeitsordner, der während des gesamten Kapitels geöffnet und unverändert sichtbar bleibt. Damit die Anleitung dabei sichtbar bleibt, verschiebst du das Tutorial vorübergehend in die rechte Seitenleiste.

Der folgende Button öffnet den VS-Code-Befehl zum Verschieben der aktuellen Ansicht. Wähle dort New Secondary Side Bar Entry (neuer Eintrag in der sekundären Seitenleiste).
