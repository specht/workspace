Eine neue Datei anlegen

Markiere im Explorer zunächst eine Datei, die direkt im Tutorial-Ordner liegt, zum Beispiel willkommen.txt. Bewegst du die Maus in den Explorer, erscheint oben rechts das Symbol Neue Datei.
