Lange Zeilen umbrechen

Mit Alt + Z schaltest du den Zeilenumbruch ein oder aus. Mit Zeilenumbruch verteilt VS Code eine lange Dokumentzeile auf mehrere sichtbare Abschnitte. In der Datei bleibt sie trotzdem eine einzige Zeile.

Bei eingeschaltetem Zeilenumbruch springt Ende zunächst ans Ende des sichtbaren Abschnitts. Ohne Zeilenumbruch springt Ende ans tatsächliche Ende der Dokumentzeile.
