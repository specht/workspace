Rückgängig und wiederholen

Mit Strg + Z machst du den letzten Bearbeitungsschritt rückgängig. Mit Strg + Shift + Z stellst du einen rückgängig gemachten Schritt wieder her.

VS Code kann eine getippte Eingabe in mehrere Bearbeitungsschritte aufteilen. Drücke die jeweilige Tastenkombination deshalb so oft, bis der verlangte Text wieder dasteht.
