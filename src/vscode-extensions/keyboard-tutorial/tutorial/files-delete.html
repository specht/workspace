Dateien und Ordner löschen

Markiere im Explorer den Eintrag, der gelöscht werden soll, und drücke Entf. VS Code fragt möglicherweise noch einmal nach, bevor der Eintrag in den Papierkorb verschoben wird.

Kontrolliere vor dem Löschen immer den Namen. Lösche in dieser Übung nur die ausdrücklich genannten Einträge.
