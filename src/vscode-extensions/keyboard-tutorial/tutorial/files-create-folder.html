Einen Ordner anlegen

Neben dem Symbol für neue Dateien findest du oben rechts im Explorer auch Neuer Ordner . Ist eine Datei markiert, entsteht der neue Ordner daneben. Ist ein Ordner markiert, entsteht der neue Eintrag innerhalb dieses Ordners.
