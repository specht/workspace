Eine Datei speichern

Änderungen im Editor werden nicht immer sofort in die Datei auf der Festplatte geschrieben. Solange eine Datei noch ungespeicherte Änderungen enthält, zeigt VS Code im Tab einen Punkt () statt des Schließen-Symbols ().

Der Punkt bedeutet: Diese Datei wurde verändert, aber noch nicht gespeichert. Mit Strg + S speicherst du die aktuelle Datei. Danach verschwindet der Punkt wieder.
