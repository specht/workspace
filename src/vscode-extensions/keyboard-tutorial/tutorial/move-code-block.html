Einen Codeblock verschieben

Die Zeile mit dem Doppelpunkt und die beiden eingerückten Zeilen darunter bilden einen Block. Wenn du alle drei vollständigen Zeilen markierst, kannst du den Block mit Alt + ↓ verschieben, ohne seine innere Einrückung zu verändern.
