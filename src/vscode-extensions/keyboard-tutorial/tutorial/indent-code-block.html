Einen Codeblock einrücken

In diesem Python-Beispiel gehören die beiden Zeilen nach der Zeile mit dem Doppelpunkt zusammen. Zusammengehörige Zeilen müssen gleich weit eingerückt sein. Die letzte Zeile gehört nicht zu diesem Block.

Zum Ein- und Ausrücken ist es egal, wo der Cursor in der Zeile steht.
