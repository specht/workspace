Text suchen

Mit Strg + F öffnest du die Suche in der aktuellen Datei. Während du den Suchbegriff eingibst, markiert VS Code passende Fundstellen im Text.

Mit F3 springst du zum nächsten und mit Shift + F3 zum vorherigen Treffer. Das funktioniert auch dann, wenn der Fokus wieder im Dokument liegt.
