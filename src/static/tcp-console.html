TCP-Konsole

Hier tippst du selbst, was über eine TCP-Verbindung geht, Zeile für Zeile, wie mit nc -C im Terminal. Jede Zeile endet beim Abschicken mit CR LF, so wie HTTP es verlangt. Mit TLS ist die Verbindung verschlüsselt, so wie bei https://. Die Verbindung beginnt in deinem Workspace: localhost ist dein Workspace, und alle anderen Rechner erreichst du so, wie dein Workspace sie erreicht.

Zum Ausprobieren:

Enter schickt die Zeile ab; in einem leeren Feld schickt es eine leere Zeile, die bei HTTP die Header beendet. Mehrere Zeilen auf einmal kannst du auch einfügen. StrgC im Eingabefeld trennt die Verbindung, wie bei nc. Die Konsole liest höchstens 1 KB pro Sekunde, wie über eine langsame Leitung; was der Server schneller schicken will, wartet so lange. Nach zwei Minuten ohne Daten trennt sie die Verbindung.
