Lernende steuern eine Schildkröte, die eine Linie hinter sich herzieht: `forward 100`, `left 90`. Das Programm läuft im Browser, und die Schildkröte zeichnet, während es läuft. Ruby, Python oder JavaScript; die Seite ist noch in Arbeit.

<table class='table'>
<tr><th>Voraussetzungen</th><td>Keine. Die Befehle sind einfache Funktionen ohne Objekte; eigene Funktionen schreiben die Lernenden später selbst.</td></tr>
<tr><th>Sprache</th><td>Ruby oder Python stellst du auf der <a href='/klasse'>Klassenseite</a> unter »Sprache« ein; JavaScript wählen die Lernenden auf der Seite selbst.</td></tr>
<tr><th>Prüfung</th><td>Endet ein Programm von selbst, gehen seine Befehle an den Server, der die Linien mit dem Bild der Aufgabe vergleicht, gleich in welcher Reihenfolge und Richtung sie gezeichnet sind. Was fehlt, zeigt die Karte gestrichelt, was zu viel ist, rot.</td></tr>
<tr><th>Gespeichert</th><td>Der Code jeder Aufgabe, für jede Sprache getrennt, bis die Person ihn löscht; auch ein angehaltenes Programm. Lehrkräfte sehen im Klassenboard nur, ob eine Aufgabe gelöst ist.</td></tr>
</table>
