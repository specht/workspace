Lernende lernen Visual Studio Code im Workspace kennen: die Teile der Oberfläche (Explorer, Editor, Terminal, Seitenleisten), Dateien, Ordner und Pfade, Checkpoints als Zwischenstände, die wichtigsten Tastenkürzel zum Bearbeiten von Text und zum Schluss ein eigenes Farbschema. Es gibt keine Aufgaben zum Prüfen; die Seite ist zum Ausprobieren und Nachschlagen, gut in der ersten Stunde nach der Anmeldung.

<table class='table'>
<tr><th>Ziele</th><td>Die Lernenden können danach<ul>
<li>die Teile von Visual Studio Code benennen und finden: Explorer, Editor, Terminal und Seitenleisten,</li>
<li>Dateien und Ordner anlegen und den Pfad einer Datei angeben,</li>
<li>vor einer größeren Änderung einen Checkpoint anlegen und zu ihm zurückkehren,</li>
<li>Text mit den wichtigsten Tastenkürzeln bearbeiten, ohne zur Maus zu greifen.</li>
</ul></td></tr>
<tr><th>Dauer</th><td>Eine knappe Doppelstunde, mit Zeit zum Herumprobieren. Wer schnell ist, macht mit <a href='/keyboard'>dem Keyboard-Tutorial</a> weiter.</td></tr>
<tr><th>Checkpoints</th><td>Ein Checkpoint sichert den geöffneten Ordner, das Projekt, und lässt sich wiederherstellen; Dateien, die erst danach dazukamen, löscht das Wiederherstellen. Das lohnt sich vor größeren Umbauten; Git ersetzt er nicht.</td></tr>
</table>
