Lernende lernen Visual Studio Code im Workspace kennen: die Teile der Oberfläche (Explorer, Editor, Terminal, Seitenleisten), Dateien, Ordner und Pfade, Checkpoints als Zwischenstände, die wichtigsten Tastenkürzel zum Bearbeiten von Text und zum Schluss ein eigenes Farbschema. Es gibt keine Aufgaben zum Prüfen; die Seite ist zum Ausprobieren und Nachschlagen, gut in der ersten Stunde nach der Anmeldung.

<table class='table'>
<tr><th>Dauer</th><td>Eine knappe Doppelstunde, mit Zeit zum Herumprobieren. Wer schnell ist, macht mit <a href='/keyboard'>dem Keyboard-Tutorial</a> weiter.</td></tr>
<tr><th>Checkpoints</th><td>Ein Checkpoint sichert den ganzen Workspace und lässt sich wiederherstellen. Das lohnt sich vor größeren Umbauten; Git ersetzt er nicht.</td></tr>
