Lernende erkunden das Netz mit Kommandozeilenwerkzeugen: die eigene Adresse, Entfernungen mit `ping` und `traceroute`, dann Schichten, Ports und der TCP-Handshake, eine eigene Verbindung mit `netcat` und HTTP von Hand. Die Seite ist die erste Hälfte von TCP → HTTP → Webserver: »Ein eigener Webserver« und »Daten aus dem Netz« setzen sie voraus. Programmierkenntnisse braucht sie nicht, nur das Terminal.

**Das Rätsel um Peru.** Die Seite stellt `rubiomonocoat.pe` als Server mit peruanischer Domain vor und fragt dann, ob die gemessenen 25 ms dazu passen. Die Aufgabe »Mindestens wie lange?« rechnet die Lichtlaufzeit nach Lima aus (111 ms), »Wo steht der Server wirklich?« lässt den Namen in der `ping`-Ausgabe lesen: ein Hoster in Belgien. Der Punkt: Eine Domain-Endung sagt nichts über den Standort. Canberra danach zeigt, wie ein wirklich weit entfernter Server aussieht. Steht der Server einmal woanders, ändert sich die Antwort in der Aufgabe von selbst, weil sie aus einer Messung im Workspace der Person kommt.

**Was schiefgeht.** `ping` und `nc -l` laufen, bis man <kbd>Strg</kbd><kbd>C</kbd> drückt. Nach der Antwort von `info.cern.ch` wartet `nc` weiter auf Eingaben; auch hier hilft <kbd>Strg</kbd><kbd>C</kbd>. Wer die leere Zeile nach den Headern vergisst, bekommt keine Antwort, bis der Server nach einer Weile aufgibt. Ohne `-C` schickt `nc` Zeilenenden ohne `\r`, und `info.cern.ch` antwortet mit `400 Bad Request`. Die erste Messung mit `curl -w` enthält das Nachschlagen des Namens, die zweite nicht. `telnet` lässt sich am einfachsten mit der Mülltonne über dem Terminal beenden.

**Die Aufgaben.** »Deine Adresse« vergleicht mit der Adresse des Workspace. »Drei Entfernungen«, »Wo steht der Server wirklich?«, »Router zählen« und »Welcher Server?« messen im Workspace der Person selbst und vergleichen mit ihrer Eingabe. »Die erste Webseite« fragt nach dem Titel von `TheProject.html` (»The World Wide Web project«), »Ein Spiel aus dem Netz« sucht das übersetzte Programm `2048`. »Ein Paket mit TTL 3«, »Wie lange dauert der Handshake?« und »Ohne leere Zeile« sind Vorhersagen.

**Weiter.** »Ein eigener Webserver« schreibt die Gegenseite von `nc -l` in Ruby, »Daten aus dem Netz« benutzt eine API aus einem Programm und einer Webseite. Für ein Gespräch eignen sich der Handshake (warum fühlt sich Australien so langsam an?) und `telnet`: Was unverschlüsselt durchs Netz geht, kann jeder Router unterwegs mitlesen.
